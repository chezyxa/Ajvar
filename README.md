# Ајвар — традиционный сербский айвар

Одностраничный презентационный сайт о сербском айваре, сделанный по принципам Apple Human Interface Guidelines.

## Разделы
- **Hero** — «Осень. В банке.» с SVG-иллюстрацией банки айвара
- **Бенто-сетка** с ключевыми фактами
- **История** — от турецкого *havyar* до лесковацкого айвара
- **Состав** — основные и необязательные ингредиенты
- **Процесс** — шесть шагов в горизонтальной карусели
- **Вкус** — сегментированный переключатель Благи / Љути / С баклажаном
- **Рецепт** — калькулятор пропорций со степпером (1–30 кг перца)
- **Подача** — с чем едят айвар

## Принципы HIG
- Системные шрифты (SF Pro → Inter как запасной вариант), крупная типографика
- Семантические цвета и автоматическая тёмная тема (`prefers-color-scheme`)
- Полупрозрачная навигация с размытием (material)
- Нативные паттерны: segmented control, stepper, chevron-ссылки
- Области нажатия не меньше 44 pt, видимый фокус, навигация с клавиатуры
- Поддержка `prefers-reduced-motion`

## Запуск
Без сборки — достаточно открыть `index.html` в браузере или:

```bash
python3 -m http.server 8000
```
